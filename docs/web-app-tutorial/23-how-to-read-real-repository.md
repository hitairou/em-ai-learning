# 23．実物の電磁気学AI支援システムを見るときの読み方

## この章で学ぶこと
- 実際のリポジトリを読む順番
- 入口（README→docs→src）の辿り方
- 分からないときの当たり方

## 作業手順
実物のリポジトリを見るときは，次の順で読む．

```txt
1．README.md
  全体説明と起動方法を見る

2．package.json
  使用パッケージと起動コマンドを見る

3．app/
  ページ構造を見る

4．components/
  画面部品を見る

5．lib/
  DB接続や共通処理を見る

6．data/ または prisma/ など
  データ保存方法を見る

7．public/
  画像や静的ファイルを見る

8．Dockerfile / docker-compose.yml
  本番実行方法を見る

9．nginx設定
  外部公開方法を見る
```
