## 作業手順
このチュートリアルの中心は，単にWebアプリを作ることではない．  
それぞれの技術がどこを担当しているかを理解することである．

```txt
Node.js
  動かす土台

Next.js
  Webアプリ全体の枠組み

TypeScript
  安全に書く言語

React
  画面部品

Tailwind CSS
  見た目

SQLite
  データ保存

Git
  ローカル履歴

GitHub
  共有とレビュー

Docker
  実行環境の箱

Nginx
  外部公開の入口
```

この対応関係を理解すれば，電磁気学AI支援システム本体のコードも順番に読めるようになる．
