# 1．Node.jsとnpmを確認する

## この章で学ぶこと
- Node.jsとnpmの役割
- バージョン確認の方法
- npmコマンドを実行できる状態の作り方

## 作業手順
## 1-1．コマンド

```bash
node -v
npm -v
```

## 1-2．解説

`node` はNode.js本体である．  
JavaScriptをブラウザ外で動かすための実行環境である．

`npm` はパッケージ管理ツールである．  
Next.js，React，better-sqlite3などの外部パッケージを導入するために使う．

## 1-3．重要な理解

Node.jsは，「ブラウザに表示するアプリ」そのものではない．  
Node.jsは，Next.jsやビルド処理，SQLite接続などをPCやサーバー上で動かす土台である．

```txt
Node.js
  実行環境

Next.js
  Node.js上で動くWebアプリ用フレームワーク

npm
  Next.jsなどを導入する管理ツール
```
