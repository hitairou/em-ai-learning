# 20．DNS，ルーター，Nginxの違い

## この章で学ぶこと
- DNS／ルーター／Nginxの違い
- どこで何が起きているか
- LAN内で開けない問題の考え方

## 作業手順
## 20-1．役割整理

```txt
DNS
  ドメインをグローバルIPへ変換する

ルーター
  グローバルIPに来た通信をLAN内のサーバーPCへ転送する

Nginx
  サーバーPCに届いたHTTP通信を内部アプリへ振り分ける
```

## 20-2．アクセスの流れ

```txt
ユーザーのブラウザ
  ↓
DNSでドメインをグローバルIPへ変換
  ↓
ルーターへ到達
  ↓
ポート転送でサーバーPCへ到達
  ↓
Nginxが受ける
  ↓
localhost:3000のNext.jsへ渡す
  ↓
Webページが返る
```

NginxはDNSではない．  
DNSは「どのグローバルIPへ行くか」を決める．  
Nginxは「サーバーに届いた後，どのアプリへ渡すか」を決める．
