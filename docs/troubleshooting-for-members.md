# トラブル対応集（初心者向け）

困ったら，まず落ち着いて次を確認します．
- どの画面で止まったか（GitHub？VS Code？ターミナル？）
- どのボタンを押した直後か
- エラーメッセージの1行目（できれば全文）

## GitHubにログインできない
- 症状：ログイン画面で進めない
- 原因：メール認証未完了，2段階認証，パスワードミスなど
- 確認する画面：GitHubログイン画面，通知
- 対処：
  1. パスワード再設定を試す
  2. メール認証が未完了なら完了する
  3. 2段階認証が必要なら設定する
- 相談先：小若さん（アカウントの状況を共有）

## リポジトリが見えない（private）
- 症状：`hitairou/em-ai-learning` が検索しても出ない
- 原因：招待未承認，権限不足
- 確認する画面：招待メール，GitHub通知（ベル）
- 対処：
  1. 招待メールの `Accept invitation` を押す
  2. 通知から招待を承認する
- 相談先：小若さん（招待の再送が必要な場合）

## Agentsタブが見えない
- 症状：上部メニューに `Agents` が無い
- 原因：アカウント，プラン，提供範囲で見えない場合がある
- 対処：`docs/vscode-copilot-fallback.md` の手順に切り替える

## Issueが作れない
- 症状：New issueが押せない，権限エラー
- 原因：権限不足
- 対処：小若さんにGitHub IDを連絡して権限付与を確認

## Projectが見えない
- 症状：Projectsタブが空，またはProjectが出ない
- 原因：表示反映待ち，権限不足
- 対処：
  1. ページ再読み込み
  2. 右上の `Link a project` が見える場合は押して選ぶ
  3. それでもダメなら小若さんに連絡

## Pull Requestが作れない
- 症状：Compare & pull requestが出ない
- 原因：pushしていない，ブランチが無い
- 対処：
  1. VS Codeで `Publish Branch` / `Sync Changes` を押す
  2. GitHubの `Pull requests` → `New pull request` から作る

## npm installで止まる
- 症状：ターミナルでエラーが出る
- 原因：Node.js未インストール，権限，ネットワーク
- 対処：
  1. `node -v` でバージョン確認
  2. Node.js LTSを入れ直す
  3. もう一度 `npm install`

## npm run devで止まる / localhostが開けない
- 症状：`http://localhost:3000` が開けない
- 原因：devサーバが起動していない，別のアプリがポート使用
- 対処：
  1. ターミナルにエラーが無いか確認
  2. `npm run dev` をやり直す
  3. 表示されたポート番号（3000以外の場合あり）を開く

## npm run buildで失敗する
- 症状：ビルドエラー
- 原因：TypeScriptエラー，importミス，型不一致など
- 確認する画面：ターミナルのエラー行
- 対処：
  1. まずエラーの最初の1〜3行を読む
  2. Copilotに「このエラーを初心者向けに説明して，直し方も提案して」と聞く
  3. 修正後に `npm run build` を再実行

## GitHub Actionsが赤い
- 症状：Actionsが×になっている
- 原因：ビルド失敗，lint失敗など
- 対処：PRの変更を見直す，必要ならPRコメントで相談
- 注意：デプロイは担当者だけが行う

## サイトが古いまま
- 原因：`main` にmergeされていない，またはデプロイが未実行
- 確認：PRがmerge済みか，Actionsが成功か
- 対処：インフラ担当に連絡する

## LAN内から https://edesign.tairoh.com が開けない
- 原因：NATループバックの制限で開けない場合がある
- 対処：スマホのモバイル回線で確認する

## 変更してはいけないファイルを触ってしまった
- 例：`.github/workflows/*`，Docker関連，Secrets関連
- 対処：
  1. PRを出す前なら，変更を戻す（わからなければ相談）
  2. PRを出した後なら，PRコメントで「誤って触ったので戻します」と書いて修正

## mainへ直接pushしてしまった
- すぐに小若さんに連絡してください（対応方針を決めます）
- 以後は必ずブランチ＋PRに戻します

## 相談先（迷ったら）
- まずIssueまたはPRにコメント（状況が残るのでおすすめ）
- 緊急なら小若さんに連絡（スクショとエラー文を添える）
